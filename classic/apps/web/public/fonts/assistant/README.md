# Assistant Bold

Unmodified static bold font from the Assistant authors' repository:
https://github.com/hafontia-zz/Assistant/blob/bb678f0dcc89dedf193fe2cd362fd0a180e69883/Fonts/TTF/Assistant-Bold.ttf

Distributed under the accompanying SIL Open Font License (`OFL.txt`).
Full Auto uses this same-origin asset when the project has no imported Assistant
Bold/ExtraBold. The ordinary font loader also resolves this family locally when
opening saved projects, so captions do not depend on Google Fonts availability.
An existing imported Assistant font remains preferred during Full Auto preflight.
