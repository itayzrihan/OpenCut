Before submission, produce a structured JSON direction containing creative_intent, complete spoken_script with speaker attribution, reference_bindings mapping the actual ordered references, storyboard_prompt, and a timed shots array. Each shot contains start, end, description, camera, character_visibility, transition and sound_effects. Explain WHY each visual/cut supports the narration, rather than giving only tokens or a word table. The shots must fill the requested duration without gaps. Supply storyboard_prompt as a precise prompt for one PHYSICAL raster storyboard sheet, with portrait panels for vertical output, timed labels outside the frames, actual character/location references, camera/action arrows and chronological order. No idle closed-mouth talking head, generic loop or restarting dialogue on entrance. At most ONE visible instance of EACH speaking character per frame, including reflections, overlays, split screens and transitions. Repeated entrances over time are allowed after the prior instance exits. Use expressive entrances/peeks when justified and anime cutaways for illustration, not continuous static talking heads.
